# Комплект пересборки Vexis

Комплект содержит скомпилированные до R8 классы приложения, ресурсы и другие файлы для пересборки APK с заменой библиотеки Xray. Лицензия собственного кода Vexis находится в `LICENSE`. Исходники приложения доступны в репозитории, а исходники и лицензии сторонних компонентов идут в отдельном архиве `license-materials`.

Для подготовки комплекта разработчик сначала собирает точную распространяемую release-конфигурацию, затем из корня проекта выполняет `powershell -NoProfile -ExecutionPolicy Bypass -File release-licensing/xray-relink/create-kit.ps1 -Destination <новая-папка>`. Если исходная сборка использует engineUpdateFeed, дополнительно указать `-EngineUpdates`. Скрипт сверяет этот выбор, идентификатор и версию со скомпилированным BuildConfig и копирует параметры приложения из текущего Gradle-файла. Он не доказывает соответствие остальных классов, ресурсов и настроек опубликованному APK: это необходимо проверить до упаковки, а хеши и параметры зафиксировать. Не включайте секреты в значение engineUpdateFeed: BuildConfig содержится в скомпилированных классах.

Получателю нужны JDK 17, Android SDK 34 и доступ к указанным в Gradle репозиториям. Указать путь к SDK стандартным способом, заменить `app/libs/libv2ray.aar` модифицированной, совместимой с приложением сборкой библиотеки, затем выполнить `gradlew.bat :app:assembleRelease`. Результат — неподписанный APK в `app/build/outputs/apk/release/`. Подпишите его собственным ключом при помощи Android SDK apksigner; приватный ключ издателя не требуется и не передаётся. Android обычно не разрешает обновить установленный APK APK-файлом с другой подписью. Удаление установленного приложения может уничтожить его данные; заранее сохраните их. На управляемом устройстве или при поставке, на которую распространяются требования к Installation Information, могут потребоваться дополнительные условия.

Комплект использует отфильтрованный AAR из точной release-сборки: в нём отсутствуют `assets/geoip.dat`, `assets/geosite.dat` и `assets/geoip-only-cn-private.dat`. Сборка повторно исключает эти три файла и из заменяющего AAR. Архив исходников wrapper содержит исходные скрипты, но эти скрипты могут скачивать сторонние геоданные; не добавляйте такие данные в поставку без отдельной проверки прав.

Комплект проверен с официальной заменой AndroidLibXrayLite `v26.11.9` → `v26.10.31`. Пересборка включила заменённые бинарники всех четырёх ABI. Тестовый APK запустился на Android 10 и подключился к VLESS-серверу. Протокол проверки находится в `release-licensing/XRAY.md` в репозитории и архиве `license-materials`. Сборка собственной модификации библиотеки из исходников и проверка полного набора материалов для распространения остаются отдельными задачами.
