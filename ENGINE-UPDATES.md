# Обновление движков

Xray и AWG входят в APK. Кнопка «Обновить» сверяет установленную версию с релизами AndroidLibXrayLite или Maven Central. Для установки нужна новая сборка Tunnel с тем же идентификатором приложения и ключом подписи.

При сборке передайте `-PengineUpdateFeed=https://ваш-сервер/engines.json`. Опубликуйте этот JSON вместе с подписанным APK.

```json
{
  "versionCode": 2,
  "xray": "26.11.9",
  "awg": "2.3.7",
  "apk": "https://example.org/tunnel.apk",
  "sha256": "<SHA-256 подписанного APK>"
}
```

В поле `xray` указывайте версию Xray Core. В поле `awg` указывайте версию Android-библиотеки AmneziaWG из Maven Central. Значения в примере замените фактическими версиями новой сборки. Увеличьте `versionCode` в Gradle перед сборкой и укажите то же значение в JSON.

Приложение сверяет SHA-256 загруженного APK. Android проверяет подпись и запрашивает подтверждение установки.
