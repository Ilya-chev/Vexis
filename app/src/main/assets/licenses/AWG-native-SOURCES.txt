AmneziaWG native library: license source index

The following upstream files correspond to module versions or replacements listed in the embedded Go build metadata of the arm64 libam-go.so shipped by amneziawg-android 2.3.7. All twelve embedded module h1 checksums match the retained Go proxy source archives, and these root license and patent files match those archives. These top-level files do not constitute a complete file-by-file notice audit or corresponding source package.
