# Правила проекта

- Android-приложение на Java с поддержкой не только новых версий Android.
- Использовать Xray Core для подключения к серверам, как в Happ и v2RayTun.
- Верхняя часть экрана занимает около четверти высоты и содержит подключение и информацию.
- Вкладки: все серверы, выбранные серверы, настройки.
- Группировать все серверы по подпискам или странам; у страны показывать флаг и название, разрешить выбрать всю страну.
- Настройка интервала обновления подписок с выбранными серверами: по умолчанию 60 минут.
- Интерфейс лаконичный: названия действий без длинных описаний.
- После реализации собрать и запустить приложение на эмуляторе, если окружение позволяет.

- В собственных элементах интерфейса приложения нельзя использовать эмодзи; для флагов и значков использовать графические ресурсы. Эмодзи в названиях серверов и подписок сохранять без изменений.

- После каждого изменения кода Android-приложения запускать `powershell -NoProfile -ExecutionPolicy Bypass -File .\install-debug.ps1`, чтобы собрать и обновить debug-версию на подключённом USB-телефоне через Gradle installDebug. Сохранять данные приложения и не удалять установленное приложение ради установки. При недоступности телефона или ошибке установки сообщить об этом пользователю.
